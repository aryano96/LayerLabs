# Course Planner 2.0 (ThunderHacks 2026)

A prerequisite- and degree-aware course planner for Algoma University CS students.
Work in progress. Placeholder course data only until the team enters real data.

Run locally: `python -m http.server` then open http://localhost:8000

## Tests
Open `tests.html` through the local server, or run `node tests.js`.

## Data
Degrees live in `data/programs.json` (name, years, required and elective course codes). All courses live in `data/courses.json`. Replace the placeholder courses with real ones; no code changes needed.
